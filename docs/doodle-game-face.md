# Doodle Game Face

Kid Mode’s nine face expressions use the Doodle Game Face artwork. The
existing emoji-to-expression mappings are preserved:

| Expression | Asset |
| --- | --- |
| neutral | `neutral.png` |
| happy | `happy.png` |
| laughing | `laughing.png` |
| sad | `sad.png` |
| surprised | `surprised.png` |
| thinking | `thinking.png` |
| angry | `angry.png` |
| loving | `loving.png` |
| sleepy | `sleepy.png` |

The dashboard copies are 320×240 PNGs; the physical robot uses the matching
GIF face-pack assets from firmware commit `09fbf7b`.
